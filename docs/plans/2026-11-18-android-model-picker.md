# Android 模型选择器修复与同版本重发计划

**目标：** 修复会话模型选择器供应商展开后空白的问题，保持 Android 2.1.2 / 45，用同一个普通 Release APK 验证并替换下载页旧包。

**设计：** `groupByModelLabel()` 和 `groupByProvider()` 创建不同的 `ModelOptionGroup` 对象，UI 的 `===` 匹配始终失败；即便改为结构相等，同名模型跨供应商及不同推理级别仍可能错配。因此直接渲染各供应商自己的模型分组，让选中态、默认选项和推理设置也限定在该分组内。保留单供应商平铺、展开状态和现有 API，不调整服务端或其他端。

## 实施步骤

1. 为真实 Compose Sheet 增加离线仪器回归：展开/收起、同名模型跨供应商、推理级别与无供应商模型；先确认旧实现失败。用可选 Gradle 属性选择 release 测试，测试包单独安装，应用仍是普通 Release。
2. 改为供应商分组内直接渲染，并修正模型数量及当前模型的推理选项范围。补充对应的纯 Kotlin 单测。
3. 执行 Release 单测、构建、手机模拟器仪器回归（`Medium_Phone_API_36.0`，不用平板）；核对版本、非 debuggable 和既有签名。若环境允许，用 Computer Use 检查普通 Release 界面；不创建模拟器专用应用包。
4. 更新发布文档的原因、验证范围、APK 大小和 SHA256。SSH 检查下载目录与空间，只原子替换 Android APK、页面和校验清单，其他产物保持不变；删除明确旧 Android 安装包。
5. 公网下载完整 APK 验 SHA256、检查页面/清单及旧 APK 清理；提交并推送本次变更，不提交凭据或构建产物。
