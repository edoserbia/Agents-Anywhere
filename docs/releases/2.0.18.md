# Agents Anywhere 2.0.18

## Agents Anywhere 队列

- DSH、Codex 和 Claude 在运行中收到的新消息统一进入 Agents Anywhere 队列，不会先作为已发送消息出现在聊天时间线。
- 当前任务结束后，队列按顺序自动发送；消息被运行时接受后立即从队列删除，队列为空时面板自动隐藏。
- 队列项目支持编辑、删除和插入。插入会先中断当前任务，将选中的项目提升到队首并立即发送。
- Web、macOS、Windows、Linux 和 Android 都从服务端同步同一份队列状态，队列面板支持折叠和展开。

## 修复

- 修复排队消息的 optimistic 气泡残留在聊天时间线的问题。
- 修复失败队列项目无法编辑、删除或重新插入的问题。
- 修复并发派发、删除和编辑之间的状态竞争，避免重复发送或误删正在发送的项目。

## 发布物

- 更新 macOS Universal、Windows x64、Linux x86_64、Android APK 和服务端至 2.0.18。
