# Agents Anywhere 2.0.25

## 本次变化

- **模型选择器显示供应商，并可按供应商折叠**：OpenScience 一个引擎就有 146 个模型、来自十几个供应商，同一个模型名还会被多家供应商同时提供（`GPT-6.1 Sol` 既来自 Command Code Proxy，也来自 AI98 Pro relay）。以前是按 id 排序的平铺长列表，标签里的供应商后缀经常被截断，也没法"先找供应商、再看它提供哪些模型"。现在三端（Web 控制台、桌面端、Android）都按供应商分组：点供应商名折叠或展开，当前选中模型所在的供应商默认展开，组内保持目录原有顺序。
- **Android 的供应商不再被吞掉**：Android 选择器原先用 `" · "` 切分标签来还原模型名，而 OpenScience 恰恰把供应商写在模型名之后，于是模型行只剩模型名，供应商被当成"思考强度"混进了下一行（显示成 `AI98 Pro (codex relay) · Extra high`）。现在改为读取目录里的结构化字段（`providerName` / `modelName` / 思考等级名），模型名、供应商、思考强度各归各位；会话页与新建会话页用的是同一套映射。
- 只有一个供应商（或完全不报供应商，例如 DSH、Codex）时保持原来的平铺列表，不额外加一层没有信息量的表头。

## 发布物
