# Agents Anywhere 2.0.21

## 本次变化

- 修复 DSH 已升级到投影版本 3 时，Agents Anywhere 收不到任何 DSH 会话和执行过程的问题。Connector 现在同时接受 `projectionVersion` 2 和 3，并按本次订阅返回的版本校验每一批事件；旧版 Host 不受影响。
- 版本 3 的 Host 会读取此前被省略的工具返回结果，因此版本 2 的同步检查点不会被复用，对应会话会完整重新校准一次。

## 发布物

- 更新 Desktop、Android、Linux 桌面客户端和 Linux Connector 至 2.0.21。
