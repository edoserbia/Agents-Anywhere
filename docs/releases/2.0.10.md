# Agents Anywhere 2.0.10

## 修复：运行中无法把消息加入队列

在一个正在执行的会话里输入下一条命令时，右下角只有暂停按钮，按回车也没有反应——**消息根本没有办法进入队列**。两个缺陷叠加造成了这一点：

**1. 按钮被暂停占用。** 界面根据「引擎是否繁忙」决定按钮含义，繁忙时按钮就是暂停。虽然当时**已经可以发送**（引擎支持接收、服务端会排队），但界面上没有任何入口能到达这个能力。

现在：**只要输入框里有内容，按钮就是发送**（运行中即入队）；只有在输入框为空时，按钮才是暂停。回车始终提交——运行中即为入队。

**2. 服务端会拒绝它本该接受的消息。** 服务端在处理发送前会读取引擎状态，而**引擎繁忙时这个读取会超时**——恰恰是队列要解决的场景。超时没有被当作「繁忙」处理，于是引擎越忙，消息越容易被拒。

现在：读取状态超时在**请求排队时视为「繁忙」并接受入队**；未请求排队时仍然照常报超时。

三端同步修复：Desktop、Web、Android。

## 版本号

`2.0.10`，Android `versionCode = 17`。
