# Agents Anywhere 2.0.7

本记录覆盖 Desktop、Android 与 Web 控制台三端。服务端与数据库无需变更（仍是 2.0.6 / `v2_36`）。

## 产品变化

### 一次提问只折叠成一块

此前折叠是按「回复之间」切分的：运行时每说一句、跑一批工具，就形成一个新的折叠块，一句句中间说明夹在中间。一个回合因此被拆成好几块，要看到结论得往下翻过所有这些内容。

现在一个回合固定只有两件事可见：

```
我提出的需求            ← 完整显示
[折叠：全部思考过程]      ← 中间所有推理、工具调用、以及中间回复
最后一次回复的总结        ← 完整显示，不可折叠
```

- 折叠块里包含该回合**全部过程以及所有中间回复**，只保留最后一次回复在外面。
- **任务进行中**：最新的那条回复仍然显示（它是当前进度），它之前的内容折叠起来；运行结束后全部收进折叠块。
- 折叠块可以点击展开/收起，读者手动展开的不会被自动收起覆盖。

### 折叠行显示开始时间

折叠行是全回合收起后唯一可见的内容，所以它现在带上该批工作的开始时间（`[MM-DD HH:mm]`）。此前时间戳只加在折叠**内部**的行上，而收起后恰恰看不到那些行，等于没有。

### Web 控制台补齐

Web 控制台此前**完全没有**这些功能——2.0.1 与 2.0.4 只改了 Desktop 与 Android：

| 功能 | 修复前 | 现在 |
| --- | --- | --- |
| 时间戳 | 无 | 每条消息与动作上方显示 |
| 回合折叠 | 无 | 与两个客户端一致 |
| 折叠行时间戳 | 无 | 有 |
| 历史请求导航 | 无 | 有 |

三端现在共用同一套折叠与时间戳模块，行为一致。

## 升级

客户端更新即可，无需改动服务端。

## 版本号

`server/agent_server/core/version.py`、`desktop-workbench/package.json`、`android/app/build.gradle.kts` 的 `versionName` 必须同时为 `2.0.7`。
