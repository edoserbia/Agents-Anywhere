# Agents Anywhere 2.0.22

## 本次变化

- OpenScience 引擎支持选择模型和**每个模型自己的思考强度**（如 `low` / `medium` / `high` / `xhigh` / `max`）。强度来自 OpenScience 为每个模型公布的档位，Agents Anywhere 不自行发明档位；没有档位的模型不显示强度选择。
- OpenScience 项目现在**由 OpenScience 自己创建**：在 Agents Anywhere 里新建项目只需填名称，目录由 OpenScience 生成（与它的网页端逻辑一致），建好的项目会出现在 OpenScience 工作台里。
- 从 Agents Anywhere 新建的会话会落在你选中的 OpenScience 项目下，不再落到服务器当前目录所属的项目。
- 同步 OpenScience 的全部项目，而不只是服务器工作目录那一个。
- 新建项目时，如果所选设备的引擎自己能创建项目（目前是 OpenScience），引擎会默认选中它，因此不需要填目录；换成其它引擎则仍需要选择目录。

## 发布物

- 更新 Desktop、Android、Linux 桌面客户端和 Linux Connector 至 2.0.22。
