# Agents Anywhere 2.1.0

排队消息和历史请求导航更新。

## 排队消息

- DSH 运行中发送的消息会进入队列，不再被误当成当前回合的直接发送。
- Desktop、Web 和 Android 都提供队列面板，可查看、编辑、删除或立即插入排队消息。
- 新版 DSH Bridge 支持调用 DSH 原生队列；未具备原生队列能力的旧 Bridge 继续使用 Agents Anywhere 服务端队列。

## 历史请求

- 展开历史请求时自动列出最近 10 条用户请求；点“更多”再加载接下来的 10 条。
- 翻页在历史面板内完成，不需要先向上滚动主对话；工具事件页会继续补取，直到请求数足够或没有更早记录。
- Desktop 历史面板避开窗口标题栏，收起按钮保持可见；加载失败可重试，重复或无进度的历史页会自动停止。

## 配套版本

这是新增 `session.queue` 有效能力和 Connector RPC 的接口版本更新。客户端、Server、Connector、Web、iOS 与 DSH Bridge 的最低配套版本均为 **2.1.0**。旧版 Bridge 不支持 DSH 原生队列时，服务端会回退到 Agents Anywhere 队列。

## 验证

- Desktop Electron + fake API：实际打开历史导航，验证自动补足 10 条、点击“更多”显示 20 条、标题栏下的收起按钮可点击；实际验证队列面板显示、编辑、删除和立即插入。
- Android emulator + fake API：实际打开历史请求弹层并加载下一页；确认队列面板与编辑、删除、立即插入入口可见。
- 该 UI 验证没有连接生产 DSH Desktop 进程；真实 DSH 原生队列联通不以 fake API 测试代替。
