# Agents Anywhere 2.0.6

本记录覆盖两个客户端。服务端与数据库无需变更（仍是 2.0.5 / `v2_36`）。

## 产品变化

### 下载页改到主域名

此前下载页只监听 `closex.cc:4001` 这个非标准端口，主域名上没有入口——读者打开 `closex.cc` 找不到任何下载链接。若所在网络封禁非标准端口，则完全无法下载。

现在 **`https://closex.cc/download`** 即可打开下载页，安装包也从该路径下载（HTTPS、标准端口）：

| 用途 | 地址 |
| --- | --- |
| 下载页 | `https://closex.cc/download` |
| APK | `https://closex.cc/download/agents-anywhere-2.0.6-debug.apk` |
| DMG | `https://closex.cc/download/Agents Anywhere-2.0.6-universal.dmg` |
| 校验和 | `https://closex.cc/download/SHA256SUMS.txt` |

旧的 `http://closex.cc:4001` 仍然可用，两个入口指向同一份文件。

### 客户端内链接同步更新

Android 的「桌面客户端下载」与「检查更新」原先指向该非标准端口，现改为上面的主域名地址。

## 升级

客户端更新即可，无需改动服务端。

## 版本号

`desktop-workbench/package.json` 与 `android/app/build.gradle.kts` 的 `versionName` 必须同时为 `2.0.6`。
