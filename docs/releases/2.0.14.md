# Agents Anywhere 2.0.14

## 修复：安卓端删除按钮点了没反应

2.0.13 里安卓端的垃圾桶图标**能显示但点不动**。原因是**回调没有传到按钮上**。

渲染链上有五个组件负责把 `onCopyMessage` 往下传，但**没有一个接受或转发
`onDeleteMessage`**。按钮因此绑定到了默认的空实现——**渲染正常，点击无效**。

现已把该动作贯穿 `MessageList` → `TimelineBlockEntries` → `TimelineProcessBlock`
→ `TimelineMessageRow`。

**真机验证**：点击垃圾桶 → 弹出确认框 → 确认后该行消失，服务器记录为已隐藏。
