# Agents Anywhere 2.0.8

## 修复

### 运行中看不到过程（重要）

一个回合里，引擎是「回复 → 工具 → 回复 → 工具」这样边做边说的。之前的折叠逻辑只把**最后一个**过程块当成「进行中」，导致同一个正在运行的回合里，前面那些过程块全是收起的。

实测你那个正在运行的会话：**3 个过程块里有 2 个被藏起来，其中一块包含 81 条记录**。所以你只看到「DSH 正在工作」，完全不知道它在做什么、也无法判断是不是卡住了。

现在**正在运行的那个回合，它的所有过程块全部展开**。回合结束后整体收起，保持界面干净。你自己手动展开/收起的不会被覆盖。

### 发消息报 Internal Server Error

发消息时服务端会向引擎查一次状态，超时是 10 秒。引擎正忙的时候可能超过 10 秒，而超时没有被捕获，直接冒成 500。现在会正确返回 504（超时），客户端能知道这是「引擎没及时响应」而不是服务端坏了。

### Web 控制台缺功能

- **项目按设备分组**：之前 Web 是所有项目平铺，同名项目在不同机器上分不清。现在和 Desktop 一样按设备分组，设备标题带在线状态和项目数。
- **消息队列**：之前 Web 完全没有队列（接口、面板、输入框行为都没有），现在补齐。
- **历史请求导航**：之前 Web 没有，现在有了。

## 新功能

### 显示引擎的计划（规划）

DSH 的 `todo_write` 和 Codex 的 `update_plan` 本来就带着完整的任务清单和每项状态，但之前被当成普通工具调用塞进折叠里了。

现在计划会单独显示成一张卡片：

```
[09-17 17:21]
计划 · 已完成 1/8
  ✓ Commit/push 2.0.7
  ◐ Audit web vs desktop
  ○ Port project-device-groups
  ○ ...
```

- 运行中默认展开（毕竟它的作用就是告诉你**还剩什么**）
- 运行结束收起成一行进度
- 每完成一项自动打勾
- 三端一致：Desktop、Android、Web

> 说明：这些数据一直都在，不需要改动 DSH 或服务端，只是之前被折叠掉了。

### 历史请求：默认显示最新 10 个

之前历史请求是**从最早开始**列的，想看最近的还得往下翻。现在：

- **默认显示最新 10 个请求**（最新的在最上面）
- **往下滚动自动加载更早的**，底部显示还剩多少条
- **点击任意一条，主聊天框直接定位过去**

这样你完全不用滚动主聊天框，只滚历史请求框就行。三端一致。
