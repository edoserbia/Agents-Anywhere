# Agents Anywhere 2.0.23

## 本次变化

- **修复 OpenScience 会话无法接管**：OpenScience 会话之前一律报告「不支持发送消息」，平台因此认为开启接管也没有用，于是根本不提供接管入口，会话一直是只读的。现在会话会如实报告自己的能力，接管后即可正常发消息。同时按真实状态区分可用性：同一时间只允许一个任务，所以运行中不能发送；中断需要有正在运行的任务；审批需要有待处理的交互。
- **模型选择里显示供应商**：OpenScience 和 DSH 的模型标题现在都带上供应它的供应商（例如 `GPT-5.6 Luna · Command Code Proxy` 与 `GPT-5.6 Luna · OpenCode Go`）。同一个模型由不同供应商提供时，可以一眼区分，不会再选错。OpenScience 有 8 个模型 id 由 2–3 家供应商同时提供。
- **Connector 版本号跟随发布**：Connector 现在与客户端同版本号（本次为 2.0.23），不再单独停留在 0.1.x。以前两台能力完全不同的机器都会显示 `0.1.7.2`，缺少 OpenScience 运行时的设备看起来也像是最新的；现在用 `uv tool list` 就能判断新旧。
- 发布流程增加 Connector 版本号这一处，并有测试防止它再次与发布版本脱节。

## 发布物

- 更新 Desktop、Android、Linux 桌面客户端和 Linux Connector 至 2.0.23。
