# Agents Anywhere 2.0.1

本记录覆盖客户端 2.0.1。服务端契约与数据库 revision 不变：本次只修改客户端渲染与导航，`CURRENT_SCHEMA_REVISION` 仍为 `v2_35`。

## 产品变化

### 过程默认折叠

一次请求会附带推理、工具调用、文件变更、子 Agent 调用和重连记录。2.0.0 里这些内容各自成行，一个问题与它的答案之间可能夹着几十行过程细节。

2.0.1 把一个回合的过程折叠成一行，默认收起，点击展开：

- **Desktop**：推理、工具、文件变更与子 Agent 调用合并为一个可折叠行，行上保留摘要（例如"推理了 1 次，执行了 2 次工具"）。当前正在执行的回合展开以便观察进度，回合结束后自动收起。
- **Android**：同样的回合级折叠，折叠行在执行中显示状态指示。
- 读者手动展开的块不会被自动收起覆盖。

### 历史请求导航

- **Desktop**：右侧新增请求列表，列出本次会话的全部提问（按时间顺序编号）。点击任意一条即滚动定位到该请求，并高亮当前选中项。
- **Android**：顶部栏在终端/文件按钮左侧新增历史按钮，打开请求列表底部面板；标题区域收窄让位给该按钮，标题仍保持单行省略。选择后滚动定位到对应请求，并暂停自动跟随最新消息。

## 版本号约定

从 2.0.1 起，每次客户端修改都提升补丁位：`2.0.1` → `2.0.2` → … → `2.0.10` → `2.0.11`。Desktop 的 `package.json` 与 Android 的 `versionName` 必须同时更新，Android `versionCode` 每次递增。详见[开发指南](../development.md#客户端版本号)。

## 验证记录

- Desktop：`renderer:typecheck` 通过；渲染层测试 293 项全部通过，其中 10 项为本次新增的回合折叠用例。
- Android：`TimelineTurnsTest` 10 项通过；把一个回合的折叠逻辑临时改坏后其中 5 项会失败，确认这些用例能真正拦住回归。
- 界面核对：Desktop 用构建产物在真实浏览器中确认折叠行的收起/展开两种状态、请求列表的编号与选中态；Android 在模拟器上确认历史按钮位于终端按钮左侧、标题收窄，以及请求列表面板的渲染。中文文案通过 APK 资源表确认 `zh-rCN` 变体存在（模拟器本身为 en-US 环境，未做中文运行时截图）。
- 安装包：macOS Universal（x86_64 + arm64）DMG 与 Android debug APK；两者均未签名，未做公证。

## 已知边界

- 安装包仍为未签名构建：macOS 首次打开需右键选择"打开"；Android 需要允许安装未知来源应用。
- 应用内自动更新的下载地址仍是占位地址，升级需要手动下载。
- 历史请求导航依赖已加载的时间线；更早的分页内容需要先滚动加载。
