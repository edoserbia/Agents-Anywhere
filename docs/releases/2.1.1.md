# Agents Anywhere 2.1.1 — Desktop / Connector

修复既有 Codex 会话在 Connector 重启、启动取消或原生连接断开后无法继续的问题。
不改 Server API、数据库结构或 AA 跨端契约；其他端可继续使用 2.1.0。

- 完整停止 Connector 时关闭其管理的 Runtime 和 native app-server，避免旧进程
  继续持有 thread writer lock，使 AA 重新启动后与自身残留进程冲突。
- Runtime 启动被断线 RPC 取消时，同样清理半启动进程；后端不可达不会阻止清理。
- 普通 WebSocket 重连保留原有 Runtime，不以网络抖动为由中断正在执行的任务。
- Codex 发送/压缩前的初始化、缓存会话探针和 thread/resume 可安全恢复一次；
  正式发送确认丢失时不自动重发，避免命令重复执行。
- 接入仓库已有 Codex App / IDE IPC owner/follower 实现及后续修复：已由原客户端
  持有的会话通过其 owner 操作，而非由第二个 app-server 抢写锁。支持 router 重连。
- Codex 配置新增默认启用的 IPC 跟随和 deep-link handoff 开关；未提供 IPC 的
  持锁者不会被强抢，也不会自动关闭原客户端。

## 升级注意

旧版已经运行的子进程不会被代码更新热替换。请在当前任务结束后完整退出 AA，
再打开新版，使旧 Connector 进程树释放。原生会话、项目文件、账号绑定和历史不需重建。
具体排查和验证边界见 [Codex 会话恢复](../codex-session-recovery.md)。
