# Agents Anywhere 2.0.9

## 重要修复

### 运行中看不到过程

一个回合里，引擎是「回复 → 工具 → 回复 → 工具」这样边做边说的。判断「回合是否在进行中」时，代码只看**引擎自己上报的状态**，而不用**会话状态**。

这两个状态在真实环境里可能不一致：会话状态由数据写入路径维护，工作一开始就变；引擎状态是一次单独的实时读取，可能还停留在 `idle`。一旦它读到 `idle`，折叠就会收起，**所有过程行被隐藏**——你只看到「DSH 正在工作」，既不知道在做什么，也无法判断是否卡死。

现在**两个来源任一显示繁忙，就算正在运行**。这里两种误判的代价不对等：把已结束的回合当成运行中，只是折叠没收起；把正在运行的回合当成已结束，就会把你在等的工作全部藏起来。

三端同步修复。

### Web 控制台补齐

- 项目按设备分组（之前是平铺，同名项目在不同机器上分不清）
- 消息队列（之前完全没有）

## 新功能

### 计划栏固定在回复栏上方

计划之前渲染在对话流里，长任务一滚动就看不见了，而且显示的是会话里最新的计划，不是当前任务的。

现在：

- **固定在回复栏上方**，跟着输入框一起固定在底部
- **默认折叠**，只显示一行进度（如「计划 · 已完成 2/6」）
- **只针对当前任务**：新任务开始后立刻切换；新任务没有计划就隐藏
- **没有计划就不显示**，不留空占位
- 点击可展开查看每一步

三端一致。

### 历史请求默认显示最新 10 个

之前从最早开始列，看最近的还得往下翻。现在默认显示最新 10 个，向下滚动自动加载更早的，点击直接定位到主聊天框。

### Windows 与 Linux 客户端

`desktop` 客户端此前只发布过 macOS。确认渲染层是**三端共享代码**（只有 3 个平台特有组件），因此 macOS 上的全部功能在 Windows 和 Linux 上同样生效。

本次提供：

| 平台 | 格式 |
| --- | --- |
| macOS | DMG（Universal，Intel + Apple Silicon） |
| Windows | NSIS 安装包（x64） |
| Linux | AppImage（x64） |

> Windows 安装包未做 Authenticode 签名，首次运行会有 SmartScreen 提示。
