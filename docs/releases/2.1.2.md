# 2.1.2 — closex.cc 新中转服务器与 macOS / Linux Connector / Android 更新

## 本次变化

- 生产中转服务迁至 `116.204.134.150`；所有设备继续使用 `https://closex.cc`，不使用 IP 地址登录。
- macOS 客户端包含队列轮询从 2 秒降至 8 秒、权限目录从 5 秒降至 30 秒的修复；页面隐藏时暂停轮询，返回页面时立即刷新。
- macOS 默认登录地址和更新下载地址指向 `closex.cc`。
- Linux Connector 更新为 2.1.2，包含 2.1.1 的 Runtime 自动恢复、Codex IPC 与连接重试修复；无需重建已有配对和历史。
- Android 队列轮询同步从 2 秒降至 8 秒，保持后台暂停，回到前台立即刷新队列。
- 本次仅发布 macOS Universal DMG（Intel / Apple Silicon 通用）、Linux Connector 源码安装包和普通 Android Release APK。没有发布新版 Windows、Linux 桌面或 iOS 安装包。
- Android Release APK 显式沿用既有 debug 证书签名，保证与此前同签名 APK 覆盖升级；它不是 debuggable 安装包，也不是正式发行证书签名。
- 下载页只展示本次实际上传的安装包，提供 SHA256 校验和；发布支持断点续传，校验通过后才更新页面。

## 兼容性

- API 保持 `/api/v2`，不新增字段、事件或迁移。其他端保持现有 2.1.x 版本，可继续连接。
- Web 版相同降频修复已于 2026-11-15 部署；生产健康检查版本与客户端 PATCH 号可不同，不代表接口不兼容。
- 本次没有将队列改为 WebSocket 推送；队列仍有前台每 8 秒的兜底轮询。
- DSH 本地桥接协议另有兼容边界：本仓库 2.1.2 Connector 使用 `endpoint.json` / JSON-RPC Bridge；B365 内置的 DSH Desktop 插件使用 MeshCall 及 `connector.json`，不能仅凭 2.1.x 版本号就认定两者兼容。该机保留原 2.1.0 Connector，不覆盖内置插件。

## 升级注意

- 更新前结束运行中的任务，完整退出旧桌面客户端后再安装，以加载新版内置 Connector。
- Connector 使用已有配置和 systemd 服务升级；不要同时启动桌面内置 Connector 与独立服务争用同一设备身份。
- 如安装包未具备 Developer ID 签名和公证，macOS 首次打开需在系统隐私与安全性设置中允许；不能将其描述为已公证发行版。
- 服务器、账号和 SSH 密码、Connector token 均不写入仓库。主机与服务位置见 [部署主机](../deployment-hosts.md)。
