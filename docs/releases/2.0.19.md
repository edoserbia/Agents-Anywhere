# Agents Anywhere 2.0.19

## 本次变化

- 所有 Agents Anywhere 消息都可以从客户端时间线删除，包括发送失败、尚未进入 Runtime 或仅存在于乐观界面的消息。
- 删除只影响 Agents Anywhere 自己的时间线，不会尝试删除 DSH、Codex 或 Claude 中的原始记录。
- 删除操作支持重复执行；消息删除后，即使 Runtime 后续再次同步相同消息，也不会在 Agents Anywhere 中恢复。
- Web、macOS、Windows、Linux 和 Android 统一使用同一套删除状态，刷新、断线重连和多端同步后仍保持一致。
- Web 和 Desktop 的删除按钮显示在对应的用户消息左侧，回复下方只保留回复操作。

## 服务端变化

- 新增本地时间线删除标记，用于持久化尚未入库消息的删除状态。
- 数据库 schema 升级到 `v2_38`。

## 发布物

- 更新 macOS Universal、Windows x64、Linux x86_64、Android APK 和服务端至 2.0.19。
