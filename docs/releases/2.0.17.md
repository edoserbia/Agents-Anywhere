# Agents Anywhere 2.0.17

## 原生队列

- DSH 繁忙时提交的消息直接进入 DSH Agent 原生队列，不再保存到 Agents Anywhere 服务端队列表。
- 桌面端和 Android 展示从 DSH 同步回来的队列，并支持编辑和删除原生队列项目。
- 队列消息在真正进入引擎时间线前不会显示成已发送的用户消息。

## 运行时边界

- DSH bridge 新增队列提交、读取、编辑和删除 RPC。
- DSH 原生队列能力由独立插件提供；需将 DSH Bridge Next 更新到 npm 包 `@agents-anywhere/dsh-bridge-next@2.0.1`，仅更新 AA 客户端或服务端不会更新 DSH Desktop 内的插件。
- 当前 AA 的 Codex app-server 与 Claude Agent SDK 适配器没有队列读取、编辑和删除接口；这些引擎不会使用 AA 服务端队列伪装成原生队列。

## 修复

- 修复队列消息在 DSH Desktop 中不可见的问题。
- 修复桌面端与 Android 端队列 optimistic 消息重复出现在对话时间线的问题。
